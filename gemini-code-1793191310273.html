Las 7 letras

Las reglas

  • Suma: si la letra pequeña va detrás, se suma. VI = 5 + 1 = 6.
  • Resta: si la letra pequeña va delante, se resta. IV = 5 − 1 = 4.
  • Solo restan I (delante de V y X), X (delante de L y C) y C (delante de D y M).
  • Repetir: una letra se repite como máximo 3 veces seguidas. III = 3, pero 4 es IV.
  • V, L y D nunca se repiten.
  • El cero no existe en los números romanos.
